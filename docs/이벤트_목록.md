## 1. 이벤트 스토어 구조 (`EventRecord`)

```json
{
  "id":       1,
  "isoTs":    "2025-01-01T09:00:00.000Z",
  "ts":       1735722000000,
  "category": "BP_EVENT",
  "event":    "ON_LOGIN",
  "level":    "success",
  "summary":  "agent@example.com",
  "payload":  { "data": { "username": "agent@example.com" } }
}
```

### 카테고리 (`CATEGORY`)

| 값 | 설명 |
|---|---|
| `SYSTEM` | 초기화·세션 복원 등 내부 시스템 이벤트 |
| `BP_EVENT` | Bright Pattern API `ON_*` 콜백 |
| `ACTION` | 버튼 클릭 등 사용자 액션 |
| `API_RESP` | API 호출 응답 (setAgentState 결과 등) |

### 레벨 (`LEVEL`)

| 값 | 우선순위 | 아이콘 | 용도 |
|---|---|---|---|
| `system` | 0 | ⚙️ | 내부 초기화 메시지 |
| `info` | 1 | 🔵 | 일반 상태 변화 |
| `success` | 2 | 🟢 | 로그인 성공, ready 상태 |
| `warn` | 3 | 🟡 | 로그아웃, not_ready |
| `error` | 4 | 🔴 | 서버 오류, 음질 저하 심각 |

## 2. 조회 API

```js
import {
  getEventLog,          // 전체 로그 (최신→오래된 순)
  getLastEvent,         // 특정 이벤트의 가장 최근 레코드
  getEventsByCategory,  // 카테고리별 필터링
  getEventsByLevel,     // 최소 레벨 이상 필터링
  onEvent,              // 비즈니스 훅 등록
  offEvent,             // 훅 해제
  clearStore,           // 스토어 초기화
} from './event-monitor.js'
```

### 비즈니스 훅 예시

```js
import { onEvent, CATEGORY, LEVEL } from './event-monitor.js'

// 신규 인터랙션 발생 시 채널 유형 분기
onEvent((rec) => {
  if (rec.event === 'ON_NEW_INTERACTION') {
    const channelType = rec.payload?.data?.channelType || rec.payload?.channelType
    if (channelType === 'chat') { /* 채팅 CRM 팝업 */ }
    else if (channelType === 'voice') { /* 콜 CRM 팝업 */ }
  }
})

// 에러 발생 시 알림
onEvent((rec) => {
  if (rec.level === LEVEL.ERROR) {
    sendSlackAlert(rec.event, rec.summary)
  }
})

// 통화 종료 후 Activity Record 저장
onEvent((rec) => {
  if (rec.event === 'ON_SAVE_ACTIVITY_RECORD') {
    const iid = rec.payload?.data?.interactionId
    saveToCRM({ interactionId: iid, ...rec.payload?.data })
  }
})
```

## 4. 콘솔에서 스토어 직접 조회

브라우저 콘솔에서는 ES 모듈 직접 import가 불가합니다.  
대신 `window.__em` 헬퍼를 `main.js`에 등록하면 편리합니다:

```js
// main.js 또는 초기화 코드에서
import * as em from './event-monitor.js'
window.__em = em

// 콘솔에서 사용
__em.getEventLog()
__em.getLastEvent('ON_LOGIN')
__em.getEventsByLevel('warn')
__em.getEventsByCategory('BP_EVENT')
```
